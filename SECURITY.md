# Security

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/sink3x/datashelf-etl-app/security/advisories/new) rather than
public issues.

Practices in this repository:

- No secrets in git: configuration comes from the environment; committed examples contain throwaway values
  only.
- gitleaks scans the full history in CI; dependency updates are reviewed and pinned manually.
- Containers run as non-root users; cloud identities follow least privilege (see
  `infra/terraform/modules/iam`).
- Cloud runtime secrets are generated by Terraform and stored in Yandex Lockbox.
